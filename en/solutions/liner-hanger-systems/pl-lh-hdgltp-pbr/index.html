PL-LH/HDGLTP/PBR

Hydraulic dual-grip liner hanger with liner top packer & polished bore receptacle

The hydraulic dual-grip liner hanger with liner top packer and polished bore receptacle is designed to suspend the liner string within the intermediate or production casing. The system design allows reciprocal and rotational movement of the liner string during run-in-hole operations. Before cementing, the hanger is hydraulically set and disconnected from the running tool. After disengagement, circulation is re-established, the liner is cemented, and the liner top packer is set to provide isolation. Additionally, the liner hanger system can be connected to a tie-back extension string and can accommodate the installation of a mechanical backup packer, if required.
